## 3. 仍阻断批准的四组问题

### B1【严重】一个迁移 state 不能同时从 committed 转成 activated 和 released

证据：S:165—166 分别规定 `committed → activated`、`committed → released`；S:177—180 把两笔事务各自绑定到该状态转换，S:170 又只让目标扫描 committed。
推断：目标先导入后，源再释放因状态已 activated 而失败；源先释放后，目标不再满足 committed，重启扫描也找不到。两笔各自“恰好一次”不等于两笔都能完成。
最小修改：持久区分“决定已提交、源释放完成、目标导入完成”这几项事实，定义两种先后及重复恢复；stopped 源由谁完成授权的释放／导出也要写清（S:153 要求 running，S:213 仅允许代为翻转）。
同组守卫补齐：abort／化身 bump 只能清 `migration = 本迁移 id` 的占用；否则一个尚未占用成员的 planned 请求被取消，可误清另一个 prepared 请求的占用（S:163、:167—168，推断）。冷页成员在 UPDATE 前须物化，不能仅依赖首次业务写。

### B2【严重】封口切点、持久基线切点和恢复计时仍被当成同一个时点

证据：S:163 冻结后“开切点 C 并等其发布”；S:194 要求在冻结同一回合把 C 封口。现 `VR/world/page_cut.ex:178` 在已有切点时不新开，`:193` 从实际开切点时的 `state.seq` 取号。
推断：冻结／封口时 seq=100，但旧切点尚未完成；其他岛继续提交，实际新切点为 120。若仍以基线截止 100 读取，会漏掉标为 cut=120 的成员段；若把 C 改为 120，封口与 handover 参数又不再对应。成员内容没变，不代表存储行 cut 没变。
最小修改：要么冻结／封口前就取得可发布的同一切点，要么分别记录流封口序号与已发布基线切点并明确映射；导入及重订阅不得混用它们。
另一时点错误：S:178 在导入 I_m 时平移时间，S:196 却要再等订阅者接上或超时才开放步进。推断：等待阶段的时长仍进入 `(now - t0_us)`（`apps/world_server/lib/world_server/movement/projectile.ex:30`），恢复会补算这段“暂停”。须把冻结终点落实到实际开放步进，并可在重启／abort 后只接纳一次。

### B3【严重】保护区“先各片应用，失败补偿”不是已声明的原子决定

证据：S:30、:303 要求各片应用并复核，全部确认才成功，否则补偿；没有持久决定／待应用版本及恢复规则。`VR/world/claims.ex:98—110` 的保护变更会实际重建热域、唤醒液体并广播，不只是暂存一张权限表。
推断：A 已应用并影响物理，B 因占用拒绝，或控制面崩溃；撤销 A 的区域记录不能撤销等待期间的物理轨迹，崩溃后也没有合同保证撤销完成。
最小修改：给 D7-A 一个明确的持久决定与生效／恢复合同；若选择允许部分暂时生效的补偿语义，须撤掉“原子”声明、把可见影响交用户选择并保证补偿最终收口。不能以“低频”或用户选择 A 代替这份合同。

### B4【严重】新增“整片液体”资格规则可能偏离 Q1，失败后也可能永久不恢复

证据：S:105 新增“一片连通液体……全部页都归本分区……否则整体冻结”；P:256 已批准的是“液体以非模拟页为墙（不流入也不取出）”。当前 `VR/world/liquids.ex:344—369` 在活跃格及下层／侧邻域步进，不要求整个水体装入同一分区。
推断：若“整片”包括模拟范围之外的连通水体，小窗口连到巨大水体便可能要求全水体迁移，否则玩家附近也冻结。这不是已批准的局部冷墙语义，也未列入 §9。
最小修改：明确液体的不可分割计算单元止于 Q1 已接纳模拟域及本步必要输入；不能把电路整分量规则无依据推广到整个水体。S:107“下次资格变化时重试”还须覆盖控制面／源恢复事件：玩家不动、资格不变时，不应让一次基础设施故障变成永久冻结。

## 4. 可保留的机制与结论

【轻】计数行 `UPDATE … RETURNING`、提交后用块及独立 aid 号源可保留。PostgreSQL 原句：“it will attempt to apply its operation to the updated version of the row”，支持同行并发更新串行领块。[官方事务隔离文档](https://www.postgresql.org/docs/current/transaction-iso.html#XACT-READ-COMMITTED)
【轻】按段继承基线链、发布本流完整页后解除引用、GC 与翻转共用 owner 行锁的方向可保留（S:185—190）；未发现独立于 B1/B2 的新严重反例。链截断写放大、预装、锁成本及超时数值留对应步骤。
【轻】窗口准入、消费 FIFO 封口、从 I_m 起补尾均比 v2 明确；本轮不要求再加并行方案或扩大测试，修复上述合同后再做对应最小反例。

**不可（最少改四条：1. 释放／导入完成状态及成员占用收敛；2. 封口与基线切点、实际解冻计时；3. D7-A 的持久决定与生效语义；4. 液体资格边界及基础设施恢复后的活性）。**
