## 2. 岛闭合（§3.2）

**【严重】2.1 推导在“静态”意义上严密，但岛的定义漏了实例 / 附件的足迹页，而基础网格会切开存量内容。**
稿:116-117 岛 = 模拟集 ∪ 电路分量页 ∪ **所触实例 / 附件的 home 页** ∪ ticket 页；稿:126 只处理“新放置的大预制件”。
反例：基础网格（稿:114“每 N³ 页一块”）把如园一棵跨页树切在两个分区；玩家在 A 侧敲它。工具命中 → g=2/g=3 行写 home 页（可能在 B）；
拆除子树写全部覆盖页（父:135“树的覆盖页集合存在根实例记录里”；`VR/world/prefabs.ex` `subtree_cells`，`gm.ex:212-213`）。
按 I5 扩展（稿:134“闭包页在裁决前已归本分区所有”），这笔普通玩家工具操作要先 T1 足迹页；若 B 侧足迹页在另一个玩家的岛里，就要 T2 合并——
一次敲树触发岛合并，或者被拒。稿只对维护入口（D9）写了“显式拒绝”，玩家工具未定。
最小修法：岛的耦合闭包加“所触实例的**覆盖页集**与所触 aid 的**槽页集**”（P1 home 记录已持久这两项，父:135-136），并在 D9 增加玩家工具的行为（推荐：先 T1，足迹页在他岛时拒绝并报原因，与维护入口同一规则）。

**【中】2.2 Q1 的模拟资格从此受分区表约束，这是对已批准 P6 / Q1 的修订，稿只在 §4b 用一句话带过。**
稿:190“合并完成前，接缝页不授予模拟资格”。P6（父:209-211）定义模拟资格 = 玩家半径并集 ∪ ticket，由模拟 owner 判定，与分区无关。
现在资格 = (玩家半径 ∪ ticket ∪ 电路分量) ∩ “本分区已拥有且外一圈也拥有的页”。后果须逐项写明：
(a) 投射物飞向接缝：停在边界并要 ticket（父:257），ticket 页须有外一圈 ⇒ 可能要 T1；拿不到就冻结。
(b) 休眠电路跨基础网格边界：玩家走近一端，Q1 ⑤ 要整分量入模拟集 ⇒ 另一端的页在他区 ⇒ 整分量冻结直到 T1 / T2 完成（不能部分授予，`VR/world/thermal.ex:239-240,340-341` 的分量按接触图扩张，不能在页边界截断，父稿第三轮 3.3-2 已指出截断 = 改解）。
(c) 身体接触热种子（`thermal.ex:379-380`）：NPC 身体在无玩家半径的页上本就不模拟，无新问题。
(d) 液体下落：只读 `dy ∈ {0,-1}`（`liquids.ex:344`），接缝上方非模拟页的液体不动，零通量成立。
(e) GM / parcel / CoarseRebuild：D9 覆盖。
以上 (a)(b) 是“岛闭合优先于 Q1 资格”的直接产物，应作为对 P6 的显式修订写入稿 §3.2 与父稿，而不是只在 §4b 提合并等待。

**【中】2.3 岛合并 / 迁移的停顿与可见性代价：可接受，但 T2 的冻结时长可以不随岛大小增长，稿未写。**
稿:156 T2 = 冻结 → 写回全部脏页 → 翻转 → 目标装页。写回只涉及脏页（m2a §5.1 切点间隔 10 s ⇒ 脏集小），但**目标装入整岛**（5³ = 125 页，如园密度每页压缩后 ≈0.6 MB base + 细节段，m2a §5.2 实测）是秒级（推断）。

## 3. 页所有权迁移协议（§3.5、§4g、§4h）

**【严重】3.1 日志追加只按“分区 epoch”校验，挡不住页级迁移后的僵尸写者，违反 I1。**
稿:160“日志追加按‘分区 epoch’一行校验……节点故障转移时 bump 分区 epoch”。T1 / T2 只翻转**页**的 owner_epoch，不 bump 分区 epoch。
反例 1（T1）：控制面翻转冷页 p 给 B 的同时，A 上一笔作者 / GM 维护事务（`gate_server/.../dispatch.ex:223` `apply_edits` 直达分片）正在提交到 p：A 的日志追加带 A 的分区 epoch ⇒ 通过 ⇒ 向调用方确认（`VR/world/edits.ex` 落日志后才确认）；
之后 A 的页段写回才被 owner_epoch 拒绝——但日志已确认、客户端已收增量。两份真值。
反例 2（T2）：稿:253“翻转前失败 → 源仍是 owner，解冻继续”——源无法区分“控制面在翻转前死”与“翻转后、通知前死”，不读 PG 就解冻即成僵尸；解冻后的提交同样只过分区 epoch。
最小修法：日志追加的 PG 事务对本笔触及的**每个页键**校验 `owner = (本分区, epoch)`（P2 行已带 level / region 列，一次索引读 / 页；S2 实测其成本，稿:160 本就要测），
且源解冻前必须读 PG owner 行。`DS/body_store.ex:26-53` 的 `claim`/`save` 是按对象（cid）校验，不是按会话，这里的同构应是按页，不是按分区。

**【严重】3.2 页段行没有流 id，多流下“最新可见版本”判定会取到未发布残留，违反 I2。**
稿:218“日志行与安全前缀带流 id”，页段只说“版本比较改为 (owner_epoch, cut_seq)”。m2a §6.1 可见性 = `max(cut_seq) ≤ P`，§6.2 恢复读 `cut_seq ≤ P`；
`DS/voxel/page_store.ex:61-73` `publish` 以单一 `voxel_safe_prefix` 行推进。块分配后 cut_seq 跨流不可比：源流的未发布残留 (e_A, 5000)（写回进程中途死亡，m2a §6.1 第 1 步靠“删 `cut_seq > P`”清理，但那是**源流**的 P）
在目标恢复页 p 时与已发布的 (e_A, 4900) 比较，取 5000——半写的切点被当成真值。
最小修法：页段行与全局 / 角色行加流 id；可见 = `cut_seq ≤ prefix(流 id)`；T1 / T2 翻转前源必须已清掉该页 `cut_seq > P_源` 的残留（m2a “开始”一步已做，但要作为迁移前置写明）。

**【中】3.3 “玩家不会自己走过接缝”没有执行机制；迁移停滞时近景窗口会跨两个分区，推翻 §4c 的前提。**
`VR/collision_stream.ex:26-36`：窗口以中心 tile 外扩 1/4 tile 滞回，玩家越过中心 tile 1/4 后窗口整体移 1 tile。
推断：岛 = 中心 ±2、外一圈 = ±3 都归本分区时，走 1 tile 后新窗口 = 旧中心 +[0,2] ⊆ 已拥有，成立；但若 T1 停滞（控制面不可用、前方页在他岛且 S2 无 T2），玩家再走 2 tile，窗口达旧中心 +4 = 他区页，
CollisionStream 只向一个 authority 取快照（`collision_stream.ex:78-89`），窗口就缺一列或被另一分片的快照替换——整窗同 seq（`客/Voxel/Net/VoxelGateCodec.cpp:663-664`）无法满足。
Scene 分工改为页集后，M4a 会把玩家移交给 B 的 Scene，但 B 的分片不拥有窗口另一半。必须写一条：**Scene 的可行走范围 = 本分区已拥有页集向内收窗口半径**（travel 盒由分区表派生），
迁移未完成时玩家在此边界被挡（可见为“临时墙”，与 D3 同类）；S2 没有 T2 时这就是两岛相向的行为（§6.2）。

**【中】3.4 T2 后 CollisionStream“以交接切点续订、不重发整窗”与 m2a R6 冲突。**
`VR/world.ex:1353`：`have_seq < state.page_store.published` ⇒ `{:error, :cursor_expired}`；`:1361` 只补 `seq > have_seq`。目标分片的 `published` 是它自己块里的数，与源的交接切点不可比：
切点 < 目标 published ⇒ 续订被拒、强制重取整窗（与稿:157 相反）；切点 > 目标 published 但目标 `entries` 里本来就没有 ≤ 切点的事务 ⇒ 补发为空，碰巧正确。
最小修法：目标接纳迁入时记录 `handover_seq`（= 源切点）与自己前推后的首个 seq，`subscribe(have_seq)` 对 `have_seq ∈ [handover_seq, 首个 seq)` 视为“无缺失”；写进 §3.5 T2。

**【中】3.5 T1 的“先写回并发布覆盖它的安全前缀”= 一次完整切点，不是一页。** P3（父:173）前缀只在“全部覆盖 C 的记录持久后”发布；一页脏就要等整批脏页写完。
冷页通常干净，但“玩家刚离开的页”常脏（稿:154 T1 用于岛向外长，前沿页就是刚变脏的）。要么接受 T1 延迟 = 切点延迟（m2a 实测常规切点中位 30 ms，可接受，写明即可），要么页级 flush + 页级日志栅栏（复杂，不建议）。

**【轻】3.6 I1–I5 在崩溃 / 网络分区下的其余判定成立。** 稿:247-253 的五种故障里，“节点与 PG 分区”靠 m2a §5.3 接纳边界显式拒绝、“翻转后目标失败”靠 PG 重装，都对；

**【轻】3.7 Scene 邻区模型只支持一个邻居。** `SS/movement/authority.ex:11-21` `partition/2` 只在两盒共面时切半空间；`SS/movement/scene.ex:333-340` 把 `neighbours` 覆盖为单元素列表。

## 4. 客户端顺序语义与协议（§4c、D5）

**【轻】4.1 稿:93 待核实项：客户端不依赖 seq 连续，只依赖单调。** 已核实：
`客/Voxel/Lod/VoxelLodWorld.cpp:1637` 每区域 `if (Transaction.Seq <= Seq) return` 丢旧；`:1639` `AppliedSeq = Max(AppliedSeq, Transaction.Seq)`；`:1764` bootstrap 置 `AppliedSeq = N`。
`客/Voxel/Net/VoxelDamageState.cpp:34,201` 按 `>=`/`<` 比较；`客/Movement/MmoPrediction.cpp:112,281` fence 按 `<` 比较（`HasGapThrough` 是 tick 空洞，不是 seq）。
服务端 `VR/log_projection.ex:39` `iterator_from(have_seq + 1)` 取 ≥，也容忍空号。近景保留协议 41 / 单一 seq 的论证**成立**（在 3.3 的窗口 ⊆ 分区前提下）。

**【严重】4.2 远景在 D5 之前不只是“只在区域重取时更新”，而是会系统性丢更新，且近景订阅游标会被远景污染；多分区 Test-only 部署在 S2 就会撞到。**
(a) `VoxelLodWorld.cpp:1637` 的区域级 `Seq` 守卫：一个 L3 区域（512 m）覆盖 8³ 个 L0 页，可属多个分片；块分配后两个分片的 seq 不可比，低块分片的所有事务都被当作旧事务丢弃，`serve_item` 重取也只把区域 Seq 置为**某一个**分片的 seq（`客/Voxel/Net/VoxelRegionFetcher.cpp:81` `Result.Header.Seq = Transaction.Seq`），另一分片继续被丢。
(b) `客/Movement/VoxelM1Client.cpp:906` `SendSubscribe(World.AppliedSeq, …)`：AppliedSeq 是所有层、所有来源的最大值；把它作为 `have_seq` 发给低块分片 ⇒ 服务端 `world.ex:1361` 过滤掉该分片全部增量；发给高块分片且 `< published` ⇒ `:1353` `cursor_expired`。
结论：D5 ③“按 L0 页片段版本”是对的，而且守卫必须从区域级移到片段级（每个片段只属一个 L0 页 ⇒ 一个 owner ⇒ 版本单调）；S2 的 Test-only 验收须把“远景可见错误”列为已知项而不是“只更新慢”。
稿:205 的措辞需改。

**【中】4.3 §4c Lamport 前推只保证 seq 单调，不保证**世代**语义。** 世代 epochs 值 = 提交 seq，客户端按相等比较（`VoxelDamageState.cpp:34`），这部分无问题；
但 `客/VoxelDamageState.cpp:15` `MinimumSeq(Anchor) > ConfirmedSeq` 与 `:201` `State.Seq < Transaction.Seq` 都假设同一格的行 seq 与事务 seq 同一流。T2 后目标分片前推 > 切点，成立；

## 5. 持久化、id 与全局账（§4e、§4f、§3.4）

**【严重】5.1 = 3.2**：页段 / 全局 / 角色行缺流 id，多流可见性判定不成立。

**【中】5.2 角色账随 T2 迁移的原子性成立，但“单独上线 / 下线”的账与页不同流，恢复合同未写。**
稿:156 T2 在同一 PG 事务翻转页与角色行；稿:214 上线由登录分区 `claim`。推断：角色 c 在 A 分区扣料（日志行在 A 流，seq 块 a），A 切点未到即下线 → 在 B 登录 claim ——
B 读到的是 A 流**最新已发布**的角色行，A 流前缀之后的扣料行只在 A 的日志里；B 不读 A 流。要么下线时强制把该角色行写回并发布（= 一次切点，同 3.5），要么 claim 时读 A 流后缀中该 cid 的行（P2 行有目标类型列，可按 cid 过滤）。二选一写进 D2。

**【中】5.3 块分配的拒旧语义：成立，但要把“块必须持久领取、崩溃不回退”写成要求。** PG `nextval` 非事务、不回收（稿:232 引文，与本人所知一致），所以新块 > 任何已领块，Lamport 前推只需换块。
稿:231“当前块起点 ≤ 该页最后版本的 seq”措辞不准：应是“当前 seq ≤ 该页最后版本 seq 时 seq := max(seq, 页版本)+1，越过块尾则换块”。

**【轻】5.4 与父稿预留的偏离要显式写。** 父:241“新格式不再把全局 seq 当跨区唯一键”；本稿选择保留 seq 派生 id、靠全局块保证唯一（稿:230）。这是合理的更小改动（实例 id 进协议 `Owner`），但应标为对父稿“第一阶段为第二阶段保留”一节的修订。

**【轻】5.5 粗层页按 L0 页片段：必要，且没有更简单的做法。** `VR/world/pages.ex:40` `overlay_unit(level, cell) = {:page, :coarse_overlay, {level, region_of(cell)}}` 整页一行，L1 页 = 8 个 L0 页、L5 页 = 32768 个，分片后必多写者。
