# 长程移动场景的帧门禁标定决策稿

- 日期：2026-08-19
- 状态：已收口（Voxia `efc5e24`）
- 前置：[`2026-08-19-long-haul-streaming-smoothness-plan.md`](2026-08-19-long-haul-streaming-smoothness-plan.md) §9.2
- 目标：为"长程持续移动"场景标定 GameThread 稳态门限。现行 3.5ms p95 按
  静止/短程场景标定,持续移动的每帧流式底载（prefetch/调度/呈现推进）使其
  常态擦线,产生与缺陷无关的失败噪声。

## 1. 标定依据（实测,组提交修复后的干净数据）

样本：`7737bb8` 之后的两轮长程（4-tile 8 段 + 12-tile 24 段 = 32 段,
每段 ~1670 帧,共 ~53,000 帧持续移动）。

| 指标 | min | p50 | p90 | max | 现门限 | 超限段 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| GT p95 | 2.85 | 3.20 | ~3.46 | **3.85** | 3.5 | 4/32 |
| GT p99 | 4.14 | 4.73 | 7.31 | 8.44 | 8.33 | 1/32 |
| frame p99 | 7.70 | 7.71 | 7.79 | 8.41 | 11.11 | 0 |
| GPU p95 | 2.58 | 2.65 | 2.73 | 2.78 | 6.0 | 0 |

静止场景（`--performance-only` 历史数据）GT p95 ≈ 3.3；移动把稳态抬约
0.3–0.5ms——这是移动的固有底载,不是缺陷。

## 2. 标定决策

**只重标 GT p95 一项**,其余全部继承静止口径：

- **traversal GT p95 = 4.5ms**
  - 观测 max 3.85 + ~17% 余量：不常态擦线,同时底载若真回归 17% 以上仍会拦截
  - 锚点：= 58% 帧预算（130fps → 7.692ms/帧）,GameThread 稳态占用过半帧预算
    即报警,为渲染提交与其他系统保留空间
- **GT p99 维持 8.33 不动**：p99 挡的是尖峰;唯一超限段（8.44,back_09）属
  偶发残余（前稿 §8 待归因项）,放宽 p99 会把它掩盖掉
- frame / GPU / hitch / severe 全部不动

## 3. 落地方式（约束落点）

- **唯一事实源**：阈值收进 `voxia_streaming_frame_gate.js` 的一张 profile 表;
  校验逻辑不复制,`validateStreamingFrameWindow(window, { profile })` 只查表
- **最小化**：默认 `stationary`,所有既有调用零变化;仅长程路由传 `traversal`
- **正交**：场景（何种运动）与判据（何为流畅）分离,新场景以后只加表项

## 4. 验收

1. 单测：两个 profile 的阈值行为 + 未知 profile 显式抛错
2. 12-tile 长程：p95 类失败清零;偶发残余（hitch 擦线/单帧 33ms/p99 8.44 类）
   **保持可见**——它们是"回头再看"的下一事项,不得被本次标定吞掉
3. `--performance-only` 语义不变（stationary 口径）

## 4.1 验证插曲：移动中 far_deadline_exceeded 偶发（记录,不属本稿范围）

标定后两轮 12-tile 均在 `out_06` 段撞上运行时 `far_deadline_exceeded`（非门禁判定）。
三轮对照(含此前的通过轮)定量：**serial 8 这一代 far 收敛三轮均为 11.1–11.7s,
贴着 12s 预算**（其他代 4–8s）,其中发布准备固定占 4.2–4.4s；通过轮是 11.2s 压线通过。
即该换区代**固有贴边**,过不过取决于当轮抖动——与本稿的判定层改动无关,但它是
"回头再看"清单里优先级最高的一项（结合既有 defect A：Far clock 起点含发布准备时间）。

因在线 12-tile 被它挡住,B 的验收改用**离线重放**（判定层变更的正确验证方式）：
用已录制的 24 段与 8 段帧数据重放新判定——

| | 旧判定 | traversal 判定 |
| --- | --- | --- |
| p95 类失败 | 4 | **0** |
| 偶发残余（hitch 擦线×2 / 单帧33ms×1 / GT p99 8.44×1） | 可见 | **保持可见** |
| 挂段（24 段轮） | 7 | 4（全为偶发残余） |
